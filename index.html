Group project · ITC327W · Live

ITS ResFix

Replaces phone calls and WhatsApp messages with a tracked complaint system for a 168-student residence: students report faults, the system assigns a worker and starts a 48-hour clock.

FlutterASP.NET Core 8Supabase/PostgreSQLCloudinaryBulkSMS

My part: Group leader and project manager for a team of 4: I ran the schedule, the change log and the risk register, and owned the auto-assignment rules risk, so rules only accept real categories and active workers.

How it works & what I learned

What it does: SMS first-login, photo complaints, AI triage of spam and emergencies, auto-assignment by category, overdue escalation to an external company, and reports with CSV export.

What I learned: Cutting scope early (native push, offline sync, an external API) is what let us ship every must-have feature, and putting a server API between the app and the database kept database keys out of the app.

Community Alert System

A bilingual (English/IsiZulu) safety platform for a local South African community: residents submit alerts, an admin approves them before the public sees them.

C#ASP.NET Core MVCASP.NET Core IdentityEntity Framework CoreSQLiteBootstrap

My part: Solo project: I wrote the spec and built the whole application myself.

How it works & what I learned

What it does: Role-based access (Admin and User), alert moderation, a limit of three submissions per user per day, community notices, incident reports, volunteer sign-up, and an admin dashboard with page-view analytics.

What I learned: Rules like "only approved alerts are public" and "three alerts a day" have to be enforced on the server, and I documented where strict enforcement would need a database transaction.
